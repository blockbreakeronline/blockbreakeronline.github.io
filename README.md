## What is Google Block Breaker?

Google Block Breaker is a browser-based game where you control a paddle and bounce a ball to break colorful blocks. Your mission? Clear all the blocks and keep the ball in play for as long as possible!

🚀 The more blocks you break, the higher your score! But watch out—things get tricky as the game speeds up.
